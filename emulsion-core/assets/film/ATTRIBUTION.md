# Film simulation LUTs

Source: <https://github.com/cedeber/hald-clut/tree/master/HaldCLUT/Film%20Simulation>

The original collection is the **RawTherapee Film Simulation Collection
2015-09-20**, released under **CC BY-SA 4.0** (see `README.txt` for the original
notice and credits: Pat David, Pavlov Dmitry, Michael Ezra).

Changes for Emulsion: every level-12 Hald CLUT (1728×1728) was resampled to
**level 6** (216×216, 36 levels per channel) with trilinear interpolation to keep
the bundled size practical. The resampled files are distributed under the same
CC BY-SA 4.0 terms.

Trademarked film names are used only to describe the look each LUT approximates.
